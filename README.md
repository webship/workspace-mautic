# @webship.co/workspace-mautic

Mautic, the open-source marketing automation platform, for the [Webship Workspace](https://github.com/webship/workspace)
dashboard: a builder that makes a real Mautic site in containers, its command-line tool, the default accounts, the
Mautic step pack wired into the workspace's testing setup, and its AI items.

The builder, the tools, the tests and CI come with the first release, `1.0.0`.
